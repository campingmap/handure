# 너와두리 캠핑장 · 한두레마을 홈페이지

충북 옥천군 청성면 한두레마을이 운영하는 너와두리 캠핑장 홈페이지입니다.

- 주소 : https://handure.net
- 호스팅 : Cloudflare Pages (이 저장소와 연결되어 자동 배포)
- 예약 문의 : 010-2309-7620 / 사무실 043-733-7620

---

## 폴더 구성

```
├─ index.html        홈
├─ village.html      한두레마을 (소개 · 인사말 · 너와두리 · 오시는 길)
├─ camping.html      너와두리 캠핑장 & 숙소 (오토캠핑 · 카라반펜션 · 편의시설 · 부대시설)
├─ notice.html       한두레 사랑방 (공지사항)
├─ 404.html          없는 주소로 들어왔을 때 보이는 페이지
│
├─ assets/
│   ├─ tailwind.config.js   색상 · 글꼴          ← 여기서 색을 바꾸면 4개 페이지에 한꺼번에 반영
│   ├─ style.css            공통 스타일
│   ├─ site.js              메뉴 · 사진 슬라이드 · 스크롤 효과
│   ├─ notices.js           공지사항 글 목록      ← 공지 내용은 이 파일에 있습니다
│   └─ board.js             게시판 동작
│
├─ images/           홈페이지에 쓰는 사진
│   └─ notice/       공지사항 첨부 사진
│
├─ robots.txt        검색엔진 안내
└─ sitemap.xml       검색엔진용 페이지 목록
```

> `사진/` 폴더와 드론 영상(`*.MP4`)은 용량이 커서 저장소에 올리지 않습니다.
> (`.gitignore` 에서 자동으로 제외됩니다. 원본은 작업용 컴퓨터에만 보관됩니다.)

## 자주 고치는 것

### 요금 · 안내 문구
해당 페이지 HTML 파일을 열어 글자만 고치면 됩니다.
- 캠핑 요금, 숙소 요금, 이용안내 → `camping.html`
- 오시는 길, 인사말 → `village.html`

### 사진 교체
`images/` 폴더에 **같은 이름으로 덮어쓰면** 됩니다.
사진은 미리 웹용으로 줄여서 넣어 주세요 (긴 변 1400~1600px 권장).

### 객실 사진 슬라이드에 사진 추가·삭제
`camping.html` 에서 `<div class="rslide">` 안의 `<img>` 줄을 추가하거나 지우면 됩니다.
화살표 · 점 · 장수 표시는 사진 수에 맞춰 자동으로 만들어집니다.

### 상단 메뉴
메뉴는 **4개 HTML 파일이 똑같은 내용을 각자** 가지고 있습니다.
메뉴 항목을 바꿀 때는 `index` `village` `camping` `notice` 네 파일을 함께 고쳐 주세요.

## 공지사항 올리기

사랑방 페이지 오른쪽 위 **[관리자]** 버튼으로 로그인하면
글쓰기 · 수정 · 삭제를 할 수 있습니다.
**쓴 글은 바로 저장되어 모든 방문자에게 보입니다.** (파일을 다시 올릴 필요 없습니다)

### 사진 첨부
1. 사진을 `images/notice/` 폴더에 넣고 저장소에 올립니다
2. 글쓰기 창에서 그 경로를 적습니다 — 예) `images/notice/2026-축제-1.jpg`

### 비밀번호 변경
Cloudflare 대시보드 → 해당 Worker → **Settings → Variables and Secrets** →
`ADMIN_PASSWORD` 수정

## 구조

```
방문자 ──▶ Cloudflare Worker ──┬─▶ D1 데이터베이스   (공지사항)
                               └─▶ 정적 파일        (HTML · 사진)
```

| 파일 | 역할 |
|---|---|
| `src/index.js` | 서버 코드 (공지 읽기·쓰기 API) |
| `wrangler.jsonc` | 배포 설정 (D1 연결 정보) |
| `db/schema.sql` | 데이터베이스 표 구조 |
| `db/seed.sql` | 기존 공지 83건 (최초 1회만 사용) |
| `db/notices-original.js` | 옮기기 전 원본 (보관용) |

**Cloudflare 에 설정된 값** (저장소에는 없습니다)

| 이름 | 용도 |
|---|---|
| `ADMIN_PASSWORD` | 관리자 비밀번호 |
| `SESSION_SECRET` | 로그인 쿠키 서명키 |

## 알아두실 점

- 관리자 비밀번호는 **Cloudflare 에만** 있습니다. 소스와 저장소 어디에도 없습니다.
- 로그인하면 서버가 서명한 쿠키가 발급되며, 브라우저에서 값을 고쳐도 통과하지 못합니다.
- 로그인은 12시간 유지됩니다.
